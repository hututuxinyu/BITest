# BI系统 - 设计态服务

## 项目概述

这是一个BI（商业智能）系统的设计态服务，提供工程管理功能。项目采用前后端分离架构，**当前版本使用模拟数据，前端可直接运行，无需后端和数据库**。

## 技术栈

### 后端（当前已注释，使用模拟数据）
- Spring Boot 2.7.18
- PostgreSQL
- JPA/Hibernate
- JUnit 4 + Mockito

### 前端
- React 18
- TypeScript
- Ant Design 5.x
- Vite
- Axios

## 快速开始

### 前端启动（推荐，当前版本）

1. 进入前端目录：
```bash
cd frontend
```

2. 安装依赖：
```bash
npm install
```

3. 启动开发服务器：
```bash
npm run dev
```

4. 访问：`http://localhost:3000`

**注意**：当前版本使用模拟数据，无需启动后端和数据库，前端可直接运行。

### 主页面布局

系统采用统一的主布局结构：

- **顶部导航栏**：系统Logo、菜单折叠按钮、用户信息
- **左侧导航菜单**：包含所有核心功能模块的入口
  - 工程管理 ✅
  - 模板管理 ⏳
  - 组件库管理 ⏳
  - 画布编辑 ⏳
  - 数据源配置 ⏳
  - 交互配置 ⏳
  - Schema生成 ⏳
  - 国际化配置 ⏳
  - Codehub集成 ⏳
- **主内容区**：根据选择的模块显示对应页面

点击左侧菜单可以切换不同的功能模块，当前只有"工程管理"模块已实现。

### 功能特性

1. **工程列表展示**：
   - 支持分页、搜索、排序
   - 支持多选和批量删除
   - 显示工程类型、描述、创建时间等信息

2. **工程管理**：
   - 创建工程（支持私有/公共工程）
   - 编辑工程信息
   - 删除工程（单个/批量）
   - 刷新列表

3. **扩展功能（待实现）**：
   - 导入模型（需要Codehub集成模块）
   - 导出模型（需要报表模块）
   - 提交Git（需要Codehub集成模块）
   - 进入工程（需要报表编辑界面）

## 界面说明

### 工程管理界面布局

- **顶部导航栏**：显示"工程管理"标题和用户信息
- **工具栏区域**：
  - 创建工程按钮
  - 删除工程按钮（需先选择工程）
  - 刷新按钮
  - 搜索框（支持按工程名称搜索）
- **工程列表**：
  - 复选框列（支持全选/单选）
  - 工程名称（可点击，待实现进入工程功能）

  - 操作列（导入模型、导出模型、提交Git）

### 对话框

1. **创建工程对话框**：
   - 工程名称（必填）
   - 工程描述（可选）
   - 工程类型（必选：私有工程/公共工程）

2. **编辑工程对话框**：同创建对话框

3. **导入模型对话框**：待实现（需要Codehub集成）

4. **导出模型对话框**：待实现（需要报表模块）

5. **提交Git对话框**：待实现（需要Codehub集成）

## 模拟数据

当前使用模拟数据，包含3个示例工程：
- 销售数据分析工程（私有工程，5个报表）
- 财务监控大屏（公共工程，3个报表）
- 用户行为分析（私有工程，8个报表）

所有操作（创建、编辑、删除）都会更新模拟数据，刷新页面后数据会重置。

## 后续开发

### 启用后端和数据库

1. 初始化数据库：
```bash
psql -U postgres -d biservice -f database/init.sql
```

2. 修改 `backend/src/main/resources/application.yml` 中的数据库配置

3. 启动后端：
```bash
cd backend
mvn spring-boot:run
```

4. 修改 `frontend/src/services/api.ts`，将 `USE_MOCK_DATA` 设置为 `false`
