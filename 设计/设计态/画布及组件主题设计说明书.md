# 画布及组件主题设计说明书

## 一、设计目标与核心原则

### 1.1 设计目标

为BI报表系统提供统一的主题管理能力，支持快速切换画布和组件的视觉样式，提升报表设计效率和视觉一致性。主题系统应覆盖画布全局样式和组件默认样式，支持预设主题和自定义主题，满足不同场景下的视觉需求。

### 1.2 核心原则

- **统一性**：主题系统统一管理画布和组件的样式配置，确保视觉风格一致
- **可扩展性**：支持预设主题和自定义主题，便于后续扩展新的主题样式
- **灵活性**：支持画布主题和组件主题独立配置，满足不同场景需求
- **易用性**：提供直观的主题选择界面，一键应用主题，降低操作门槛
- **兼容性**：主题应用不影响用户已自定义的配置，支持主题与手动配置的混合使用

## 二、主题系统架构

### 2.1 系统架构

主题系统采用分层架构设计，包含主题定义层、主题管理层和应用层：

```
┌─────────────────────────────────────┐
│         主题应用层                    │
│  (CanvasConfigTab / ComponentTab)   │
│  - 主题选择UI                        │
│  - 主题应用逻辑                      │
└──────────────┬──────────────────────┘
               │
┌──────────────▼──────────────────────┐
│         主题管理层                    │
│  (ThemeManager / ThemeUtils)        │
│  - 主题注册与查找                    │
│  - 主题应用与合并                    │
│  - 主题配置转换                      │
└──────────────┬──────────────────────┘
               │
┌──────────────▼──────────────────────┐
│         主题定义层                    │
│  (Theme Config / Theme Types)       │
│  - 主题数据结构定义                  │
│  - 预设主题配置                      │
│  - 主题扩展接口                      │
└─────────────────────────────────────┘
```

### 2.2 主题分类

主题系统分为两类：

1. **画布主题**：应用于画布全局配置，包括背景、边框、字体等
2. **组件主题**：应用于组件默认样式，包括背景、边框、阴影、内边距、标题样式等

### 2.3 主题作用范围

| 主题类型 | 作用范围 | 影响对象 |
|---------|---------|---------|
| 画布主题 | 画布全局 | 画布背景、边框、全局字体、网格样式 |
| 组件主题 | 组件默认样式 | 组件背景、边框、阴影、内边距、标题样式 |

## 三、主题配置结构设计

### 3.1 主题数据结构

```typescript
/**
 * 主题配置接口
 */
interface Theme {
  /** 主题唯一标识 */
  id: string;
  
  /** 主题名称 */
  name: string;
  
  /** 主题描述 */
  description?: string;
  
  /** 画布配置 */
  canvas: CanvasThemeConfig;
  
  /** 组件默认样式配置 */
  component: ComponentThemeConfig;
}

/**
 * 画布主题配置
 */
interface CanvasThemeConfig {
  /** 背景颜色 */
  backgroundColor?: string;
  
  /** 背景类型 */
  backgroundType?: 'solid' | 'gradient' | 'image' | 'transparent';
  
  /** 渐变方向（当backgroundType为gradient时） */
  gradientDirection?: 'top-bottom' | 'left-right' | 'diagonal' | 'radial';
  
  /** 渐变起始色 */
  gradientStartColor?: string;
  
  /** 渐变结束色 */
  gradientEndColor?: string;
  
  /** 背景图片URL（当backgroundType为image时） */
  backgroundImage?: string;
  
  /** 图片缩放方式 */
  imageScale?: 'stretch' | 'tile' | 'center';
  
  /** 边框是否启用 */
  borderEnabled?: boolean;
  
  /** 边框宽度 */
  borderWidth?: number;
  
  /** 边框样式 */
  borderStyle?: 'solid' | 'dashed' | 'dotted';
  
  /** 边框颜色 */
  borderColor?: string;
  
  /** 全局字体 */
  globalFont?: string;
  
  /** 网格显示 */
  gridVisible?: boolean;
  
  /** 网格大小 */
  gridSize?: number;
}

/**
 * 组件主题配置
 */
interface ComponentThemeConfig {
  /** 组件背景颜色 */
  backgroundColor: string;
  
  /** 边框配置 */
  border?: {
    /** 是否启用 */
    enabled: boolean;
    /** 边框宽度 */
    width: number;
    /** 边框样式 */
    style: 'solid' | 'dashed' | 'dotted';
    /** 边框颜色 */
    color: string;
    /** 圆角半径 */
    radius: number;
  };
  
  /** 阴影配置 */
  shadow?: {
    /** 是否启用 */
    enabled: boolean;
    /** X轴偏移 */
    offsetX: number;
    /** Y轴偏移 */
    offsetY: number;
    /** 模糊半径 */
    blur: number;
    /** 阴影颜色 */
    color: string;
    /** 透明度（0-1） */
    opacity: number;
  };
  
  /** 内边距配置 */
  padding: {
    /** 上边距 */
    top: number;
    /** 右边距 */
    right: number;
    /** 下边距 */
    bottom: number;
    /** 左边距 */
    left: number;
  };
  
  /** 标题样式配置 */
  title?: {
    /** 是否显示 */
    visible: boolean;
    /** 字体大小 */
    fontSize: number;
    /** 字体颜色 */
    color: string;
    /** 字体类型 */
    font: string;
  };
}
```

### 3.2 预设主题设计

#### 3.2.1 浅色主题（Light Theme）

**设计理念**：经典的浅色主题，适合日常办公和数据分析场景，提供清晰的视觉层次和良好的可读性。

**画布配置**：
- 背景色：`#FFFFFF`（纯白色）
- 背景类型：`solid`（纯色）
- 边框：不启用
- 全局字体：`微软雅黑`
- 网格显示：开启
- 网格大小：`10px`

**组件配置**：
- 背景色：`#FFFFFF`（白色）
- 边框：启用，宽度`1px`，样式`solid`，颜色`#E5E7EB`（浅灰），圆角`4px`
- 阴影：启用，偏移`(0, 2)`，模糊`4px`，颜色`#000000`，透明度`0.1`
- 内边距：上下左右各`16px`
- 标题：字体大小`16px`，颜色`#1F2937`（深灰），字体`inherit`

#### 3.2.2 深色主题（Dark Theme）

**设计理念**：护眼的深色主题，适合长时间查看和演示场景，减少视觉疲劳，提供专业的视觉体验。

**画布配置**：
- 背景色：`#1F2937`（深灰蓝）
- 背景类型：`solid`（纯色）
- 边框：不启用
- 全局字体：`微软雅黑`
- 网格显示：开启
- 网格大小：`10px`

**组件配置**：
- 背景色：`#374151`（中灰）
- 边框：启用，宽度`1px`，样式`solid`，颜色`#4B5563`（中灰），圆角`4px`
- 阴影：启用，偏移`(0, 4)`，模糊`8px`，颜色`#000000`，透明度`0.3`
- 内边距：上下左右各`16px`
- 标题：字体大小`16px`，颜色`#F9FAFB`（浅灰白），字体`inherit`

## 四、画布主题设计

### 4.1 画布主题作用范围

画布主题应用于画布的全局配置，影响整个报表的视觉基础：

| 配置项 | 说明 | 默认值（浅色主题） | 默认值（深色主题） |
|--------|------|------------------|------------------|
| 背景颜色 | 画布整体背景色 | `#FFFFFF` | `#1F2937` |
| 背景类型 | 背景显示方式 | `solid` | `solid` |
| 边框设置 | 画布边框样式 | 不启用 | 不启用 |
| 全局字体 | 画布默认字体 | `微软雅黑` | `微软雅黑` |
| 网格显示 | 是否显示网格辅助线 | 开启 | 开启 |
| 网格大小 | 网格间距 | `10px` | `10px` |

### 4.2 画布主题应用逻辑

1. **主题选择**：用户在画布配置面板的"样式设置"分组中选择主题
2. **主题应用**：选择主题后，系统自动将主题中的画布配置应用到当前画布配置
3. **配置合并**：主题应用采用覆盖策略，直接替换对应配置项的值
4. **实时预览**：主题应用后立即在画布上显示效果

### 4.3 画布主题UI设计

在`CanvasConfigTab`组件的"样式设置"分组中，添加主题选择器：

```
样式设置
├── 主题选择
│   ├── [浅色主题] [深色主题]  (Radio.Button组)
│   └── 描述文字：当前选中主题的描述
├── 背景类型
├── 背景色
└── ...
```

**UI交互**：
- 使用`Radio.Button`组件展示主题选项
- 每个主题按钮显示主题名称
- 选中主题后，下方显示主题描述
- 主题切换时，自动应用画布配置并实时预览

### 5.4 组件主题应用策略

组件主题应用时，需要将主题配置映射到组件的各个样式属性：

```typescript
/**
 * 应用主题到组件属性
 */
function applyThemeToComponent(
  componentProperty: ComponentProperty,
  theme: Theme
): ComponentProperty {
  const themeComponent = theme.component;
  
  return {
    ...componentProperty,
    // 应用背景色
    backgroundColor: themeComponent.backgroundColor,
    
    // 应用边框配置
    border: themeComponent.border ? {
      ...componentProperty.border,
      ...themeComponent.border,
    } : componentProperty.border,
    
    // 应用阴影配置
    shadow: themeComponent.shadow ? {
      ...componentProperty.shadow,
      ...themeComponent.shadow,
    } : componentProperty.shadow,
    
    // 应用内边距配置
    padding: themeComponent.padding ? {
      ...componentProperty.padding,
      ...themeComponent.padding,
    } : componentProperty.padding,
    
    // 应用标题样式配置
    title: themeComponent.title && componentProperty.title ? {
      ...componentProperty.title,
      fontSize: themeComponent.title.fontSize,
      color: themeComponent.title.color,
      font: themeComponent.title.font,
    } : componentProperty.title,
  };
}
```

## 六、主题应用流程

```
    ↓

    ↓
应用主题到画布配置
    ↓

    ↓

    ↓
```

```
    ↓

    ↓
更新组件属性状态
    ↓
触发组件重新渲染
    ↓
```

- **画布主题**：在画布配置面板中，用户主动选择主题时应用

```typescript
 * 自定义主题接口

interface CustomTheme extends Theme {
  /** 是否为用户自定义主题 */
  isCustom: boolean;
  /** 创建时间 */
  createTime?: string;
  /** 创建者 */
  creator?: string;
}

/**
 * 主题管理服务
 */
interface ThemeService {
  /**
   * 保存自定义主题
   */
  saveCustomTheme(theme: CustomTheme): Promise<void>;
  
  /**
   * 获取用户自定义主题列表
   */
  getCustomThemes(): Promise<CustomTheme[]>;
  
  /**
   * 删除自定义主题
   */
  deleteCustomTheme(themeId: string): Promise<void>;
}
```

### 9.2 主题导入导出

支持主题配置的导入导出功能，便于主题的分享和复用：

```typescript
/**
 * 导出主题配置为JSON
 */
function exportTheme(theme: Theme): string {
  return JSON.stringify(theme, null, 2);
}

/**
 * 从JSON导入主题配置
 */
function importTheme(json: string): Theme {
  return JSON.parse(json) as Theme;
}
```

### 10.2 开发优先级

#### 第一阶段（核心功能）
1. 创建主题类型定义（`types/theme.ts`）
2. 创建主题配置文件（`config/themes.ts`），包含浅色和深色两个预设主题
3. 创建主题工具函数（`utils/themeUtils.ts`）
4. 在画布配置Tab中添加主题选择器
5. 在组件属性Tab中添加主题选择器

#### 第二阶段（功能完善）
1. 实现主题应用逻辑
2. 实现主题切换时的实时预览
3. 优化主题选择UI交互
4. 添加主题应用成功提示

#### 第三阶段（扩展功能）
1. 支持自定义主题创建
2. 支持主题导入导出
3. 支持主题预览功能
4. 支持主题管理（保存、删除、重命名）

### 10.3 注意事项

1. **配置覆盖策略**：主题应用采用覆盖策略，直接替换配置项的值，不保留用户原有配置
2. **状态同步**：主题应用后需要同步更新组件状态，确保UI实时反映变化
3. **错误处理**：主题不存在或应用失败时，需要给出明确的错误提示
4. **性能考虑**：主题应用不应影响画布渲染性能，使用防抖处理批量更新
5. **兼容性**：确保主题配置与现有配置结构兼容，不影响已有功能

## 十一、使用场景

### 11.1 场景一：快速应用统一风格

**场景描述**：用户创建新报表时，希望快速应用统一的视觉风格。

**操作流程**：
1. 用户在画布配置面板中选择画布主题（如"浅色主题"）
2. 系统自动应用画布背景、边框、字体等配置
3. 用户在组件属性面板中选择组件主题（如"浅色主题"）
4. 系统自动应用组件背景、边框、阴影等样式
5. 报表整体呈现统一的视觉风格

### 11.2 场景二：切换主题风格

**场景描述**：用户需要将报表从浅色主题切换到深色主题。

**操作流程**：
1. 用户在画布配置面板中将主题从"浅色主题"切换到"深色主题"
2. 系统自动更新画布背景色为深色
3. 用户逐个选择组件，在组件属性面板中将主题切换到"深色主题"
4. 系统自动更新组件样式为深色风格
5. 报表整体切换为深色主题

### 11.3 场景三：混合使用主题

**场景描述**：用户希望画布使用浅色主题，但某些组件使用深色主题以突出显示。

**操作流程**：
1. 用户在画布配置面板中选择"浅色主题"
2. 系统应用浅色画布配置
3. 用户选择需要突出的组件，在组件属性面板中选择"深色主题"
4. 系统仅对该组件应用深色主题样式
5. 实现画布与组件的主题差异化

## 十二、总结

主题系统为BI报表提供了统一的视觉风格管理能力，通过预设主题和自定义主题，用户可以快速创建具有一致视觉风格的报表。系统设计遵循统一性、可扩展性、灵活性的原则，支持画布主题和组件主题的独立配置，满足不同场景下的视觉需求。
