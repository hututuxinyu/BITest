# 右侧面板配置管理系统设计说明书

## 一、概述

### 1.1 文档目的

本文档详细描述BI系统右侧属性配置面板的完整设计，涵盖画布配置、组件属性配置、数据源配置、交互配置等核心功能模块，为系统开发、维护和扩展提供指导。

### 1.2 适用范围

- 前端开发人员：了解配置面板的实现细节和交互逻辑
- 后端开发人员：了解配置数据的结构和API接口设计
- 产品设计人员：了解功能边界和用户体验设计
- 测试人员：了解功能点和测试场景

### 1.3 系统定位

右侧属性配置面板是BI设计态系统的核心配置界面，提供统一的配置入口，支持用户对画布全局属性、组件属性、数据源绑定、交互行为进行可视化配置，实现所见即所得的设计体验。

## 二、系统架构

### 2.1 整体架构

右侧属性配置面板采用分层架构设计：

```
┌─────────────────────────────────────────┐
│          PropertyPanel (主面板)          │
│  ┌───────────────────────────────────┐  │
│  │      Tab 切换区域 (Tabs)          │  │
│  │  ┌──────┐ ┌──────┐ ┌──────┐      │  │
│  │  │画布  │ │组件  │ │数据  │ │交互│  │
│  │  │配置  │ │属性  │ │来源  │ │设置│  │
│  │  └──────┘ └──────┘ └──────┘      │  │
│  └───────────────────────────────────┘  │
│  ┌───────────────────────────────────┐  │
│  │      配置内容区域 (Tab Content)    │  │
│  │  ┌─────────────────────────────┐  │  │
│  │  │  CanvasConfigTab             │  │  │
│  │  │  ComponentPropertyTab        │  │  │
│  │  │  DatasourceConfigTab         │  │  │
│  │  │  InteractionConfigTab        │  │  │
│  │  └─────────────────────────────┘  │  │
│  └───────────────────────────────────┘  │
│  ┌───────────────────────────────────┐  │
│  │      操作按钮区域 (Actions)        │  │
│  │  [重置]                            │  │
│  └───────────────────────────────────┘  │
└─────────────────────────────────────────┘
```

### 2.3 状态管理

配置面板采用React Hooks进行状态管理：

- **画布配置状态**：`canvasConfigState` - 存储当前画布配置
- **组件属性状态**：`componentPropertyState` - 存储当前组件属性
- **数据源配置状态**：`datasourceConfigState` - 存储当前数据源配置
- **交互配置状态**：通过`item.interactionConfig`直接管理
- **Tab激活状态**：`activeTab` - 当前激活的Tab

### 2.4 数据流转

```
用户操作
  ↓
配置变更事件 (onChange)
  ↓
状态更新 (useState/useCallback)
  ↓
立即应用 (实时同步到画布)
  ↓
保存到Schema (持久化)
```

## 三、画布配置模块

### 3.1 功能概述

画布配置模块用于配置报表画布的全局属性，包括基础设置和样式设置。仅在未选中任何组件时显示。

### 3.2 基础设置

#### 3.2.1 报表名称

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| 报表名称 | 文本输入框 | "未命名报表" | 支持最多20个字符，同步显示在画布顶部标题区 |

**实现细节**：
- 使用`Input`组件，设置`maxLength={20}`
- 实时同步到画布标题区
- 保存到`CanvasConfig.title`字段

#### 3.2.2 画布尺寸

| 配置项 | 类型 | 默认值 | 范围 | 说明 |
|--------|------|--------|------|------|
| 画布宽度 | 数字输入框 | 1920px | 800~4000px | 支持px/%/vw单位 |
| 画布高度 | 数字输入框 | 1080px | 600~3000px | 支持px/%/vh单位 |

**实现细节**：
- 使用`InputNumber`组件，配合单位选择器
- 宽度单位：px、%、vw
- 高度单位：px、%、vh
- 实时更新画布尺寸

#### 3.2.3 适配模式

| 配置项 | 类型 | 默认值 | 选项 | 说明 |
|--------|------|--------|------|------|
| 适配模式 | 下拉选择 | "等比缩放" | 等比缩放/拉伸填充/固定宽高比 | 控制画布在不同屏幕尺寸下的适配方式 |

**实现细节**：
- `scale`：等比缩放，保持宽高比
- `stretch`：拉伸填充，不保持宽高比
- `fixed`：固定宽高比（16:9/4:3/自定义）

#### 3.2.4 网格设置

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| 网格显示 | 开关 | 开启 | 开启后在画布上显示网格辅助线 |
| 网格大小 | 下拉选择 | 10px | 仅网格显示开启时可配置，选项：10px/20px/30px/50px |

**实现细节**：
- 网格显示使用`Switch`组件
- 网格大小仅在网格显示开启时显示
- 实时更新画布网格显示

#### 3.2.5 报表描述

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| 报表描述 | 文本域 | 空 | 支持最多500个字符，用于报表说明，可在导出时显示 |

**实现细节**：
- 使用`Input.TextArea`组件，设置`rows={3}`，`maxLength={500}`
- 保存到`CanvasConfig.description`字段

### 3.3 样式设置

#### 3.3.1 背景类型

| 配置项 | 类型 | 默认值 | 选项 | 说明 |
|--------|------|--------|------|------|
| 背景类型 | 下拉选择 | "纯色" | 纯色/渐变/图片/透明 | 选择画布背景的显示方式 |

**实现细节**：
- 根据选择的背景类型，动态显示对应的配置项
- 保存到`CanvasConfig.backgroundType`字段

#### 3.3.2 纯色背景

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| 背景色 | 颜色拾取器 | #F5F5F5 | 支持RGB/HEX输入，实时预览背景效果 |

**实现细节**：
- 使用颜色预览块 + 文本输入框
- 支持HEX格式输入（如#F5F5F5）
- 实时更新画布背景色

#### 3.3.3 渐变背景

| 配置项 | 类型 | 默认值 | 选项 | 说明 |
|--------|------|--------|------|------|
| 渐变方向 | 下拉选择 | "从上到下" | 从上到下/从左到右/对角线/径向 | 选择渐变色的方向 |
| 渐变起始色 | 颜色拾取器 | #FFFFFF | - | 渐变起点颜色 |
| 渐变结束色 | 颜色拾取器 | #F5F5F5 | - | 渐变终点颜色 |

**实现细节**：
- 渐变方向：`top-bottom`、`left-right`、`diagonal`、`radial`
- 保存到`CanvasConfig.gradientDirection`、`gradientStartColor`、`gradientEndColor`字段

#### 3.3.4 图片背景

| 配置项 | 类型 | 默认值 | 选项 | 说明 |
|--------|------|--------|------|------|
| 背景图片 | 上传组件 | - | - | 支持本地上传或URL输入 |
| 图片缩放 | 下拉选择 | "拉伸" | 拉伸/平铺/居中 | 选择背景图片的显示方式 |

**实现细节**：
- 使用`Upload`组件，`listType="picture-card"`，`maxCount={1}`
- 图片缩放选项：`stretch`、`tile`、`center`
- 保存到`CanvasConfig.backgroundImage`、`imageScale`字段

#### 3.3.5 画布边框

| 配置项 | 类型 | 默认值 | 范围/选项 | 说明 |
|--------|------|--------|----------|------|
| 画布边框 | 开关 | 关闭 | - | 开启后显示画布边框 |
| 边框宽度 | 数字输入框 | 1px | 1~10px | 仅边框开启时可配置 |
| 边框样式 | 下拉选择 | "实线" | 实线/虚线/点线 | 仅边框开启时可配置 |
| 边框颜色 | 颜色拾取器 | #E5E7EB | - | 仅边框开启时可配置 |

**实现细节**：
- 边框相关配置仅在边框开启时显示
- 保存到`CanvasConfig.borderEnabled`、`borderWidth`、`borderStyle`、`borderColor`字段

#### 3.3.6 全局字体

| 配置项 | 类型 | 默认值 | 选项 | 说明 |
|--------|------|--------|------|------|
| 全局字体 | 下拉选择 | "微软雅黑" | 系统字体/微软雅黑/思源黑体/自定义 | 设置画布中所有组件的默认字体 |

**实现细节**：
- 自定义字体支持上传字体文件
- 保存到`CanvasConfig.globalFont`字段

### 3.4 数据结构

```typescript
interface CanvasConfig {
  // 基础设置
  width: number;              // 画布宽度（px）
  height: number;             // 画布高度（px）
  adaptMode: 'scale' | 'stretch' | 'fixed'; // 适配模式
  gridVisible: boolean;       // 网格显示
  gridSize: number;           // 网格大小（px）
  title: string;              // 画布标题
  description: string;        // 报表描述
  
  // 样式设置
  backgroundType: 'solid' | 'gradient' | 'image' | 'transparent';
  backgroundColor: string;     // 背景色（HEX）
  gradientDirection?: 'top-bottom' | 'left-right' | 'diagonal' | 'radial';
  gradientStartColor?: string;
  gradientEndColor?: string;
  backgroundImage?: string;   // 背景图片URL
  imageScale?: 'stretch' | 'tile' | 'center';
  borderEnabled: boolean;
  borderWidth?: number;
  borderStyle?: 'solid' | 'dashed' | 'dotted';
  borderColor?: string;
  globalFont: string;         // 全局字体
}
```

## 四、组件属性配置模块

### 4.1 功能概述

组件属性配置模块用于配置选中组件的属性，包括基础信息、位置尺寸、样式设置、标题设置以及组件特有属性。所有组件共用基础属性配置，同时根据组件类型动态加载特有属性。

### 4.2 标签设置（表单组件专用）

**适用范围**：表单类型组件（form-*、control-*），不包括表单容器（form-form）

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| 标签文本 | 文本输入框 | 组件默认名称 | 表单组件前显示的文本标签，支持自定义 |

**实现细节**：
- 根据组件类型自动识别是否为表单组件
- 保存到`item.propsValues.formLabel`字段
- 支持空字符串（允许不显示标签）

### 4.3 组件特有属性

**功能说明**：根据组件定义（`componentDefinition.propsSchema`）动态加载组件特有属性配置。

**属性类型支持**：

1. **布尔类型** (`boolean`)
   - 使用`Switch`组件
   - 示例：显示图例、显示网格线等

2. **枚举类型** (`enum`)
   - 使用`Select`组件
   - 从`options`数组加载选项
   - 示例：图表类型、对齐方式等

3. **数字类型** (`number`)
   - 使用`InputNumber`组件
   - 支持`min`、`max`、`step`限制
   - 示例：字号、间距等

4. **字符串类型** (`string`)
   - 使用`Input`组件
   - 支持`maxLength`限制
   - 示例：文本内容、占位符等

**实现细节**：
- 从`componentDefinition.propsSchema`读取属性定义
- 从`item.propsValues`读取当前值
- 使用`defaultProps`作为默认值
- 实时同步到组件实例

### 4.4 位置尺寸

| 配置项 | 类型 | 默认值 | 范围 | 说明 |
|--------|------|--------|------|------|
| X 坐标 | 数字输入框 | 组件当前x值 | - | 相对于画布左上角的水平距离 |
| Y 坐标 | 数字输入框 | 组件当前y值 | - | 相对于画布左上角的垂直距离 |
| 宽度 | 数字输入框 | 组件默认宽度 | 100~画布宽度-20 | 组件宽度 |
| 高度 | 数字输入框 | 组件默认高度 | 50~画布高度-20 | 组件高度 |
| 等比缩放 | 开关 | 开启 | - | 开启后修改宽度/高度时，保持组件宽高比不变 |

**实现细节**：
- X/Y坐标实时同步到`item.position`
- 宽度/高度实时同步到`item.size`
- 支持画布拖拽同步修改坐标和尺寸
- 保存到`ComponentProperty.x`、`y`、`width`、`height`、`keepAspectRatio`字段

### 4.5 样式设置

#### 4.5.1 背景色

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| 背景色 | 颜色拾取器 | #FFFFFF | 组件背景，支持透明色（rgba） |

**实现细节**：
- 使用颜色预览块 + 文本输入框
- 支持HEX和RGBA格式
- 保存到`ComponentProperty.backgroundColor`字段

#### 4.5.2 边框设置

| 配置项 | 类型 | 默认值 | 范围/选项 | 说明 |
|--------|------|--------|----------|------|
| 边框设置 | 开关 | 关闭 | - | 开启后可配置边框属性 |
| 边框宽度 | 数字输入框 | 1px | 1~5px | 仅边框开启时可配置 |
| 边框样式 | 下拉选择 | "实线" | 实线/虚线/点线 | 仅边框开启时可配置 |
| 边框颜色 | 颜色拾取器 | #E5E7EB | - | 仅边框开启时可配置 |
| 圆角 | 数字输入框 | 0px | 0~20px | 仅边框开启时可配置 |

**实现细节**：
- 边框相关配置仅在边框开启时显示
- 保存到`ComponentProperty.border`对象：
  ```typescript
  border: {
    enabled: boolean;
    width: number;
    style: 'solid' | 'dashed' | 'dotted';
    color: string;
    radius: number;
  }
  ```

#### 4.5.3 阴影效果

|--------|------|--------|------|------|
| 阴影效果 | 开关 | 关闭 | - | 开启后可配置阴影属性 |

### 4.6 标题设置

| 配置项 | 类型 | 默认值 | 范围/选项 | 说明 |
|--------|------|--------|----------|------|
| 标题显示 | 开关 | 开启 | - | 关闭后隐藏组件标题栏 |

- 标题相关配置仅在标题显示开启时显示

  ```typescript
  title: {
    visible: boolean;
    text: string;
    font: string;
    fontSize: number;
    color: string;
    align: 'left' | 'center' | 'right';
    position: 'top' | 'bottom' | 'left' | 'right';
  }
  ```

### 4.7 数据结构

```typescript
interface ComponentProperty {
  // 基础信息
  id: string;                 // 组件ID
  name: string;               // 组件名称
  description: string;        // 组件描述
  visible: boolean;           // 可见性
  locked: boolean;            // 锁定状态
  zIndex: number;             // 层级
  
  // 位置尺寸
  x: number;                  // X坐标
  y: number;                  // Y坐标
  width: number;              // 宽度
  height: number;             // 高度
  keepAspectRatio: boolean;  // 等比缩放
  
  // 样式设置
  backgroundColor: string;    // 背景色
  border?: {
    enabled: boolean;
    width: number;
    style: 'solid' | 'dashed' | 'dotted';
    color: string;
    radius: number;
  };
  shadow?: {
    enabled: boolean;
    offsetX: number;
    offsetY: number;
    blur: number;
    color: string;
    opacity: number;
  };
  padding: {
    top: number;
    right: number;
    bottom: number;
    left: number;
  };
  
  // 标题设置
  title?: {
    visible: boolean;
    text: string;
    font: string;
    fontSize: number;
    color: string;
    align: 'left' | 'center' | 'right';
    position: 'top' | 'bottom' | 'left' | 'right';
  };
  
  // 组件特有配置（根据组件类型动态扩展）
  specificConfig?: Record<string, any>;
}
```

## 五、数据源配置模块

### 5.1 功能概述

数据源配置模块用于配置组件的数据来源和绑定方式，支持数据集绑定和静态数据配置。仅图表类组件显示此Tab。

### 5.2 数据来源配置

## 六、交互配置模块

### 6.1 功能概述

| 事件优先级 | 数字输入框 | 多个事件时的执行顺序（1~10，数值越大越先执行） |

**实现细节**：
- 支持关联组件值进行条件判断
- 条件类型：等于/不等于/大于/小于/包含/范围等

#### 6.4.1 动作类型

### 6.5 数据结构

```typescript
interface InteractionConfig {
  events: Array<{
    id: string;               // 事件ID
    name: string;             // 事件名称
    eventType: 'click' | 'hover' | 'change' | 'load' | 'filter' | 'select' | 'input';
    priority: number;         // 优先级（1-10）
    
    // 条件设置
    conditions?: {
      enabled: boolean;
      logic: 'AND' | 'OR';

        field: string;
        operator: string;
        value: any;
      }>;
    };
    
    // 动作配置
    actions: Array<{
      id: string;

        type: 'none' | 'loading' | 'message';

        apiUrl: string;

        body?: any;
        auth?: {
          type: 'none' | 'basic' | 'token';
          config: any;
        };
        paramMapping?: Array<{
          source: string;     // 数据来源
          target: string;     // 目标参数名
        }>;
      };
    }>;
  }>;
}
```

## 七、Tab切换逻辑

### 7.1 切换规则

| 选中状态 | 显示的Tab | 默认激活Tab |
|----------|-----------|-------------|
| 未选中组件 | 画布配置 | 画布配置 |
| 选中单个组件（图表类） | 组件属性、数据来源、交互设置 | 组件属性 |
| 选中单个组件（非图表类） | 组件属性、交互设置 | 组件属性 |
| 选中多个组件 | 提示信息（不显示Tab） | - |

### 7.2 自动切换逻辑

- **未选中组件时**：自动切换到"画布配置"Tab
- **选中组件时**：自动切换到"组件属性"Tab（仅在从0个选中变为1个选中时切换，避免编辑时跳转）
- **切换时机**：仅在选中数量变化时切换，不在组件内容变化时切换

### 7.3 实现细节

```typescript
// 根据选中状态自动切换Tab
useEffect(() => {
  if (prevSelectedCountRef.current !== selectedCount) {
    if (selectedCount === 0) {
      setActiveTab('canvas');
    } else if (selectedCount === 1 && item) {
      // 只在从0个选中变为1个选中时才切换到component
      if (prevSelectedCountRef.current === 0) {
        setActiveTab('component');
      }
    }
    prevSelectedCountRef.current = selectedCount;
  }
}, [selectedCount, item]);
```
