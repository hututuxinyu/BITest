# BI系统设计态 - 主页面布局设计

## 概述

主页面采用统一的布局结构，包含所有核心功能模块的入口，用户可以通过左侧导航菜单快速切换不同功能模块。

## 布局结构

### 1. 顶部导航栏（Header - 高度：60px）

**位置**：固定在页面顶部

**内容**：
- **左侧**：
  - 菜单折叠/展开按钮
  - 系统Logo/名称："BI系统 - 设计态"
- **右侧**：
  - 用户头像和用户名
  - 用户下拉菜单（个人设置、退出登录）

**样式**：
- 背景色：#e1f5ff（浅蓝色）
- 固定定位，z-index: 1000
- 阴影效果

### 2. 左侧导航菜单（Sider - 宽度：250px，可折叠）

**位置**：固定在左侧，位于顶部导航栏下方

**菜单项**（按核心功能模块）：
1. **工程管理** (`/projects`) - FolderOutlined
2. **模板管理** (`/templates`) - AppstoreOutlined
3. **组件库管理** (`/components`) - BlockOutlined
4. **画布编辑** (`/canvas`) - EditOutlined
5. **数据源配置** (`/datasource`) - DatabaseOutlined
6. **交互配置** (`/interaction`) - InteractionOutlined
7. **Schema生成** (`/schema`) - FileTextOutlined
8. **国际化配置** (`/i18n`) - GlobalOutlined
9. **Codehub集成** (`/codehub`) - GitlabOutlined

**特性**：
- 支持折叠/展开
- 折叠后宽度：80px（只显示图标）
- 当前选中项高亮显示
- 点击菜单项切换路由

**样式**：
- 背景色：#fff4e1（浅黄色）

### 3. 主内容区（Content）

**位置**：位于顶部导航栏下方，左侧菜单右侧

**特性**：
- 自适应宽度（根据左侧菜单折叠状态调整）
- 内边距：24px
- 背景色：#fafafa
- 圆角：4px
- 根据路由显示不同的功能页面

**内容**：
- 每个功能模块有独立的页面组件
- 页面标题（带图标）
- 功能内容区域

## 路由配置

```typescript
Routes:
  /projects -> ProjectManagement
  /templates -> TemplateManagement
  /components -> ComponentLibrary
  /canvas -> CanvasEditor
  /datasource -> DatasourceConfig
  /interaction -> InteractionConfig
  /schema -> SchemaGenerator
  /i18n -> I18nConfig
  /codehub -> CodehubIntegration
  / -> 重定向到 /projects
```

## 响应式设计

- **左侧菜单折叠**：点击顶部导航栏的折叠按钮，菜单折叠后只显示图标
- **主内容区自适应**：根据菜单折叠状态自动调整左边距
- **过渡动画**：菜单折叠/展开有平滑的过渡效果（0.2s）

## 样式规范

### 颜色方案
- **顶部导航栏**：#e1f5ff（浅蓝色）
- **左侧菜单**：#fff4e1（浅黄色）
- **主内容区**：#fafafa（浅灰色）
- **卡片背景**：#ffffff（白色）

### 尺寸规范
- **顶部导航栏高度**：60px
- **左侧菜单宽度**：250px（展开）/ 80px（折叠）
- **主内容区内边距**：24px
- **卡片圆角**：4px

## 使用说明

1. **启动应用**：
   ```bash
   cd frontend
   npm install
   npm run dev
   ```

2. **访问应用**：`http://localhost:3000`

3. **导航使用**：
   - 点击左侧菜单项切换功能模块
   - 点击顶部折叠按钮收起/展开菜单
   - 点击用户头像查看用户菜单

4. **当前状态**：
   - 工程管理模块已实现，使用模拟数据
   - 其他模块显示"待实现"提示
   - 所有模块都可以通过菜单访问
