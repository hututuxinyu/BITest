# BI系统深浅主题配色设计方案（React+ECharts适配版）
## 一、设计核心原则
1. **视觉统一**：全量图表/组件复用同一套色彩体系，深浅主题仅调整色值明度，不改变色彩语义；
2. **可读性优先**：文字与背景对比度≥4.5:1（核心文字）/≥3:1（辅助文字），杜绝模糊、看不清的情况；
3. **重点突出**：核心指标用主色强化，正向/负向数据用差异化辅助色区分，非核心元素弱化处理；
4. **ECharts深度适配**：所有图表配置（坐标轴、网格、图例、系列色）与React组件配色强绑定，无视觉割裂。

### 2. ECharts通用配置封装（src/utils/echartsConfig.js）
```javascript
import { getCurrentTheme } from '../styles/theme';

// 生成ECharts基础配置（所有图表复用）
export const getEchartsBaseConfig = (isDark) => {
  const theme = getCurrentTheme(isDark);
  return {
    // 标题配置
    title: {
      textStyle: {
        fontSize: 16,
        color: theme.textPrimary,
        fontWeight: 500
      }
    },
    // 坐标轴配置
    xAxis: {
      axisLine: { lineStyle: { color: theme.border } },
      axisLabel: { color: theme.textSecondary, fontSize: 12 },
      axisTitle: { color: theme.textSecondary, fontSize: 13 },
      splitLine: { lineStyle: { color: `${theme.bgTertiary}80` } } // 透明度0.5
    },
    yAxis: {
      axisLine: { lineStyle: { color: theme.border } },
      axisLabel: { color: theme.textSecondary, fontSize: 12 },
      axisTitle: { color: theme.textSecondary, fontSize: 13 },
      splitLine: { lineStyle: { color: `${theme.bgTertiary}80` } }
    },
    // 图例配置
    legend: {
      textStyle: { color: theme.textSecondary, fontSize: 12 }
    },
    // 提示框配置
    tooltip: {
      backgroundColor: theme.bgSecondary,
      borderColor: theme.border,
      textStyle: { color: theme.textPrimary }
    },
    // 背景透明（继承容器背景）
    backgroundColor: 'transparent'
  };
};

// 柱状图专用配置
export const getBarConfig = (isDark, seriesData) => {
  const theme = getCurrentTheme(isDark);
  const baseConfig = getEchartsBaseConfig(isDark);
  return {
    ...baseConfig,
    series: seriesData.map((item, index) => {
      const colorList = [theme.dataPrimary, theme.dataPositive, theme.dataNegative, theme.dataNeutral1, theme.dataNeutral2];
      return {
        type: 'bar',
        name: item.name,
        data: item.data,
        itemStyle: { color: colorList[index % colorList.length] },
        label: {
          show: true,
          color: theme.textPrimary,
          fontSize: 12,
          borderColor: colorList[index % colorList.length],
          borderWidth: 1
        }
      };
    })
  };
};

// 其他图表配置（折线图/饼图等）按此逻辑封装...
```

### 3. 主题切换适配
1. 通过React Context管理`isDark`状态，切换时同步更新所有ECharts实例的配置；
2. ECharts组件通过`useEffect`监听`isDark`变化，调用`echartsInstance.setOption`重新渲染；
3. 表格组件通过CSS变量绑定主题色，切换时更新`:root`下的CSS变量。

## 五、视觉校验清单
1. 所有文字与背景的对比度是否达标（核心≥4.5:1，辅助≥3:1）；
2. 同一数据语义的颜色在深浅主题中是否一致（如增长始终为绿色系）；
3. 多系列图表的颜色是否按「核心→正向→中性」顺序取色，无颜色冲突；
4. 图表悬浮态/hover态的颜色是否为基础色的加深/加亮版本，无突兀感；
5. 深色主题下无纯黑/纯白，浅色主题下无高饱和刺眼色；
6. 表格行hover、按钮hover的背景色与基础背景色区分明显，交互反馈清晰。

这套方案可直接落地到React+ECharts项目中，所有配色和配置均按「统一、可读、突出」的原则设计，确保大屏视觉协调且数据重点清晰。如需调整某类图表的细节配置（如仪表盘进度条宽度、饼图颜色数量），可基于此方案微调。
