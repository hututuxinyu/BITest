# BI系统右侧属性配置面板设计说明书

## 一、设计目标与核心原则

### 1.1 设计目标

为 BI 系统提供统一、高效、可扩展的属性配置面板，支持用户对画布全局、各类组件（图表 / 表单等）、数据源、交互逻辑进行可视化配置，降低操作门槛，同时覆盖从基础样式到高级功能的全场景配置需求，适配不同用户（新手 / 专业用户）的使用习惯。

### 1.2 核心原则

- **分层分类**：按 "画布→组件属性（基础 + 特有）→数据源→交互" 分层，同类属性聚合，逻辑清晰
- **按需显示**：根据组件类型动态加载对应配置项，组件属性区自动合并基础配置与特有配置，避免冗余
- **可视化操作**：颜色、位置、尺寸等配置支持可视化选择（如颜色拾取器、拖拽调整），减少手动输入
- **实时预览**：配置变更实时同步至画布，所见即所得
- **兼容扩展**：支持新增组件类型、数据源类型、交互事件的配置扩展，预留扩展接口

## 二、面板整体架构

### 2.1 布局结构

属性配置面板采用侧边栏固定布局（默认靠右，支持用户切换至左侧），宽度默认 360px，支持拖拽调整宽度（300px~500px）。

**整体结构**：
```
┌─────────────────────────────────┐
│  配置 Tab 栏（4个核心tab）      │
├─────────────────────────────────┤
│                                 │
│  属性内容区（按tab分类展示）    │
│  （支持折叠/展开分组，滚动）    │
│                                 │
├─────────────────────────────────┤
│  操作按钮区（应用/重置/保存）   │
└─────────────────────────────────┘
```

### 2.2 区域功能描述

| 区域 | 功能描述 |
|------|---------|
| **配置 Tab 栏** | 4 个核心 tab：「画布配置」「组件属性」「数据源配置」「交互设置」，支持快速切换；选中组件时默认激活「组件属性」tab，未选中组件时默认激活「画布配置」tab |
| **属性内容区** | 按 tab 分类展示具体配置项，支持折叠 / 展开分组，滚动加载多配置项；「组件属性」tab 内自动合并基础配置与特有配置，按逻辑顺序排列 |
| **操作按钮区** | 统一操作：「应用」「重置」「保存为模板」，支持快捷键（应用：Ctrl+S） |

### 2.3 面板基础样式

- **背景色**：#F5F7FA（浅灰），与画布背景形成区分
- **边框**：左侧 1px solid #E5E7EB（分隔线）
- **字体**：全局微软雅黑，标题 14px（加粗），配置项名称 13px，说明文字 11px（#999999）
- **间距**：配置项上下间距 12px，分组间距 20px，内边距 16px
- **Tab 栏样式**：选中 tab 下方显示 2px solid #165DFF（主色调），未选中 tab 文字颜色 #666666，hover 时 #333333

## 三、核心 Tab 配置详情

### 3.1 画布配置（全局画布属性）

仅当未选中任何组件时激活，配置项按「基础设置」「样式设置」分组，覆盖画布全局属性。

#### 3.1.1 基础设置

| 配置项 | 类型 | 默认值 | 操作说明 |
|--------|------|--------|----------|
| 画布宽度 | 数字输入框 | 1920px | 支持输入数值（范围：800~4000），单位默认 px，支持切换（px/%/vw） |
| 画布高度 | 数字输入框 | 1080px | 同宽度配置，范围：600~3000 |
| 适配模式 | 下拉选择 | 等比缩放 | 选项：等比缩放 / 拉伸填充 / 固定宽高比（16:9/4:3 / 自定义） |
| 网格显示 | 开关 | 开启 | 开启后画布显示网格线，辅助组件对齐 |
| 网格大小 | 下拉选择 | 10px | 选项：10px/20px/30px/50px，仅网格显示开启时可配置 |
| 画布标题 | 文本输入框 | 未命名报表 | 支持输入 20 字以内，同步显示在画布顶部标题区 |
| 报表描述 | 文本域 | - | 支持输入 500 字以内，用于报表说明，可在导出时显示 |

#### 3.1.2 样式设置

| 配置项 | 类型 | 默认值 | 操作说明 |
|--------|------|--------|----------|
| 背景类型 | 下拉选择 | 纯色 | 选项：纯色 / 渐变 / 图片 / 透明 |
| 背景色 | 颜色拾取器 | #F5F5F5 | 支持 RGB/HEX 输入，实时预览背景效果，仅纯色模式可用 |
| 渐变方向 | 下拉选择 | 从上到下 | 选项：从上到下 / 从左到右 / 对角线 / 径向，仅渐变模式可用 |
| 渐变起始色 | 颜色拾取器 | #FFFFFF | 渐变起点颜色，仅渐变模式可用 |
| 渐变结束色 | 颜色拾取器 | #F5F5F5 | 渐变终点颜色，仅渐变模式可用 |
| 背景图片 | 上传 + 预览 | - | 支持本地上传 / URL 输入，可配置图片缩放（拉伸 / 平铺 / 居中），仅图片模式可用 |
| 画布边框 | 开关 + 配置 | 关闭 | 开启后可配置边框宽度（1~10px）、样式（实线 / 虚线 / 点线）、颜色 |
| 全局字体 | 下拉选择 | 微软雅黑 | 选项：系统字体 / 微软雅黑 / 思源黑体 / 自定义（上传字体文件），统一画布字体 |

### 3.2 组件属性（基础属性 + 特有属性合并）

选中任意组件时激活，配置项按「基础信息」「位置尺寸」「样式设置」「标题设置」「组件特有配置」的逻辑顺序分组，前 4 组为所有组件通用基础属性，最后一组根据组件类型动态加载特有配置。

#### 3.2.1 基础信息（通用）

| 配置项 | 类型 | 默认值 | 操作说明 |
|--------|------|--------|----------|
| 组件名称 | 文本输入框 | 组件类型 + ID | 如 "柱状图 - comp-001"，支持自定义命名（20 字以内），用于组件管理 |
| 组件描述 | 文本域 | - | 支持输入 100 字以内，用于说明组件功能，仅在组件列表中显示 |
| 组件 ID | 文本输入框 | 自动生成 | 唯一标识（如 comp-001），支持手动修改（字母 + 数字 + 下划线），需全局唯一 |
| 可见性 | 开关 | 开启 | 关闭后组件在画布和预览中隐藏，仅编辑模式可见（灰色占位） |
| 锁定状态 | 开关 | 关闭 | 开启后组件无法拖动、修改尺寸，仅可配置属性 |
| 层级（zIndex） | 数字输入框 | 1 | 控制组件叠加顺序，数值越大越靠上（范围：1~100） |

#### 3.2.2 位置尺寸（通用）

| 配置项 | 类型 | 默认值 | 操作说明 |
|--------|------|--------|----------|
| X 坐标 | 数字输入框 | 组件当前 x 值 | 相对于画布左上角的水平距离，支持输入 / 画布拖拽同步修改 |
| Y 坐标 | 数字输入框 | 组件当前 y 值 | 相对于画布左上角的垂直距离，同 X 坐标配置 |
| 宽度 | 数字输入框 | 组件默认宽度 | 支持输入 / 拖拽组件边缘同步修改（范围：100~ 画布宽度 - 20） |
| 高度 | 数字输入框 | 组件默认高度 | 同宽度配置（范围：50~ 画布高度 - 20） |
| 等比缩放 | 开关 | 开启 | 开启后修改宽度 / 高度时，保持组件宽高比不变 |
| 对齐方式 | 按钮组 | - | 选项：左对齐 / 居中对齐 / 右对齐 / 上对齐 / 下对齐（相对于画布或选中的多个组件） |

#### 3.2.3 样式设置（通用）

| 配置项 | 类型 | 默认值 | 操作说明 |
|--------|------|--------|----------|
| 背景色 | 颜色拾取器 | #FFFFFF | 组件背景，支持透明色（rgba） |
| 边框设置 | 开关 + 配置 | 关闭 | 开启后可配置边框宽度（1~5px）、样式（实线 / 虚线 / 点线）、颜色、圆角（0~20px） |
| 阴影效果 | 开关 + 配置 | 关闭 | 开启后可配置阴影 X/Y 偏移（-20~20px）、模糊度（0~50px）、颜色、透明度 |
| 内边距 | 数字输入框 | 16px | 组件内部上下左右边距，支持单独配置（上 / 下 / 左 / 右）或统一配置 |

#### 3.2.4 标题设置（通用）

| 配置项 | 类型 | 默认值 | 操作说明 |
|--------|------|--------|----------|
| 标题显示 | 开关 | 开启 | 关闭后隐藏组件标题栏 |
| 标题文本 | 文本输入框 | 组件默认标题 | 如 "月度销售额"，支持自定义（30 字以内） |
| 标题字体 | 下拉选择 | 全局字体 | 可单独配置，覆盖全局字体 |
| 标题字号 | 数字输入框 | 16px | 范围：12~24px |
| 标题颜色 | 颜色拾取器 | #333333 | 标题文本颜色 |
| 标题对齐 | 下拉选择 | 居中 | 选项：左对齐 / 居中 / 右对齐 |
| 标题位置 | 下拉选择 | 顶部 | 选项：顶部 / 底部 / 左侧 / 右侧（部分组件如表格仅支持顶部） |

#### 3.2.5 组件特有配置（按类型动态加载）

根据选中组件的类型（图表 / 表格 / 表单等），动态加载专属配置项，按组件功能分组。

##### 3.2.5.1 图表类组件（柱状图 / 折线图 / 饼图等）

| Y 轴单位 | 文本输入框 | - | 如 "万元""件"，支持自定义单位 |
| Y 轴范围 | 下拉 + 输入 | 自动适配 | 选项：自动适配 / 自定义（输入最小值、最大值） |

**交互设置**

### 3.3 数据源配置（组件数据绑定）

支持组件与数据集关联，配置项按「绑定方式」「数据集配置」「数据筛选」「字段映射」分组，所有组件共用统一的数据源配置逻辑，仅根据绑定类型动态加载子配置项。

#### 3.3.1 绑定方式

| 配置项 | 类型 | 默认值 | 操作说明 |
|--------|------|--------|----------|
| 绑定类型 | 下拉选择 | 关联数据集 | 选项：关联数据集 / 静态数据 / API 接口 / 自定义 SQL |
| 数据集选择 | 下拉选择 | - | 选择系统中已创建的数据集（按业务分类展示），仅关联数据集模式可用 |
| 数据更新方式 | 下拉选择 | 手动刷新 | 选项：手动刷新 / 自动刷新（配置刷新间隔：1~60 分钟）/ 实时同步（仅支持 API） |

#### 3.3.2 数据集配置（按绑定类型动态加载）

##### 3.3.2.1 关联数据集

| 配置项 | 类型 | 操作说明 |
|--------|------|----------|
| 数据集筛选 | 按钮 | 点击打开筛选面板，配置数据集的固定筛选条件（如 "区域 = 华东"） |
| 参数关联 | 按钮 | 关联全局参数或其他组件的输出值（如筛选器的日期范围），作为动态筛选条件 |
| 数据预览 | 弹窗预览 | 预览当前配置下的数据集前 10 条数据，验证数据正确性 |

##### 3.3.2.2 静态数据

| 配置项 | 类型 | 操作说明 |
|--------|------|----------|
| 数据编辑 | 表格编辑 | 直接在面板内编辑数据（新增 / 删除行、修改单元格值），支持导入 Excel/CSV |
| 字段类型设置 | 下拉选择 | 为每列设置字段类型（文本 / 数字 / 日期 / 布尔），用于数据格式化 |
| 数据校验 | 按钮 | 校验数据格式正确性（如日期格式、数字范围），提示错误行 |

##### 3.3.2.3 API 接口

| 配置项 | 类型 | 操作说明 |
|--------|------|----------|
| API 地址 | 文本输入框 | 输入接口 URL（支持 HTTP/HTTPS），支持变量占位符（如 ${dateRange}） |
| 请求方式 | 下拉选择 | 选项：GET/POST/PUT/DELETE |
| 请求头 | 表格编辑 | 新增请求头参数（如 Content-Type、Authorization） |
| 请求参数 | 表格编辑 | 配置查询参数 / 请求体参数，支持关联组件值（如筛选器输出） |
| 响应格式 | 下拉选择 | 选项：JSON/XML/CSV，配置数据路径（如 JSON 的 data.list） |
| 鉴权设置 | 下拉选择 | 选项：无 / Basic Auth/Token Auth，配置对应鉴权信息 |

##### 3.3.2.4 自定义 SQL

| 配置项 | 类型 | 操作说明 |
|--------|------|----------|
| 数据库选择 | 下拉选择 | 选择已配置的数据库连接（MySQL/Oracle/PostgreSQL 等） |
| SQL 编辑器 | 代码编辑器 | 支持 SQL 语法高亮、自动补全、格式化，支持参数占位符（如 ${startDate}） |
| SQL 校验 | 按钮 | 校验 SQL 语法正确性，提示错误位置 |
| 执行预览 | 弹窗预览 | 执行 SQL 并预览前 10 条结果，验证查询正确性（仅支持查询语句 SELECT） |

#### 3.3.3 数据筛选

| 配置项 | 类型 | 操作说明 |
|--------|------|----------|
| 筛选条件 | 条件编辑器 | 新增 / 删除筛选条件，支持多条件组合（AND/OR），条件类型：等于 / 不等于 / 包含 / 范围等 |
| 筛选字段 | 下拉选择 | 选择数据集中的字段作为筛选维度 |
| 筛选值 | 输入 / 选择 | 支持手动输入、关联组件值、固定值选择 |

#### 3.3.4 字段映射

| 配置项 | 类型 | 操作说明 |
|--------|------|----------|
| 组件字段 | 下拉选择 | 组件需要的字段（如图表的 X 轴字段、表格列） |
| 数据源字段 | 下拉选择 | 关联数据集中的对应字段，实现字段映射（支持一对一 / 多对一） |
| 字段别名 | 文本输入框 | 自定义组件字段的显示名称（如数据源字段 "sales_amount" 映射为 "销售额"） |

### 3.4 交互设置（组件事件与联动）

配置组件的触发事件、条件判断、执行动作，支持组件间联动，按「事件配置」「条件设置」「动作配置」分组，所有组件共用统一的交互配置框架。

#### 3.4.1 事件配置

| 配置项 | 类型 | 操作说明 |
|--------|------|----------|
| 触发事件 | 下拉选择 | 按组件类型显示支持的事件：点击 /hover/ 值变化 / 加载完成 / 筛选变更等 |
| 事件名称 | 文本输入框 | 自定义事件名称（如 "点击柱状图钻取"），用于管理多个事件 |
| 事件优先级 | 数字输入框 | 多个事件时的执行顺序（1~10，数值越大越先执行） |

#### 3.4.2 条件设置

| 配置项 | 类型 | 操作说明 |
|--------|------|----------|
| 条件开关 | 开关 | 关闭后直接执行动作，不判断条件 |
| 条件逻辑 | 下拉选择 | 选项：满足所有条件 / 满足任一条件（多条件时） |
| 条件配置 | 条件编辑器 | 配置触发条件：如 "点击的数值> 100""选择的日期范围包含当前月"，支持关联组件值 |

#### 3.4.3 动作配置

| 配置项 | 类型 | 操作说明 |
|--------|------|----------|
| 动作类型 | 下拉选择 | 选项：刷新组件 / 筛选组件 / 钻取数据 / 跳转页面 / 显示弹窗 / 执行 API / 自定义脚本 |
| 目标组件 | 下拉选择 | 选择动作作用的组件（如 "刷新表格 comp-003"），支持多选 |
| 动作参数 | 表单配置 | 按动作类型动态加载参数：如筛选组件需配置筛选字段和值，跳转页面需配置 URL |
| 动作执行顺序 | 拖拽排序 | 多个动作时，按顺序执行 |
| 动作反馈 | 下拉选择 | 选项：无反馈 / 显示加载动画 / 显示提示文字（配置提示内容） |

**示例：柱状图点击钻取交互**

- **触发事件**：点击（当前组件 comp-001）
- **条件设置**：无
- **动作配置**：钻取数据（目标组件：表格 comp-003），参数：{month: "${data.month}", year: "${data.year}"}

## 四、操作按钮区与交互体验

### 4.1 操作按钮

| 按钮名称 | 功能描述 | 样式说明 |
|----------|----------|----------|
| 应用 | 保存当前 tab 的配置并实时同步至画布，不关闭面板 | 主按钮（#165DFF），左侧图标 "√" |
| 重置 | 恢复当前 tab 的配置项至上次应用前的状态，需二次确认 | 次按钮（#FFFFFF，边框 #E5E7EB） |
| 保存为模板 | 将当前组件的所有配置（组件属性 + 数据源 + 交互）保存为模板，支持后续复用 | 次按钮（#FFFFFF，边框 #E5E7EB） |

### 4.2 交互体验优化

- **实时预览**：
  - 基础属性（颜色、尺寸、位置等）修改后实时同步至画布，无需点击 "应用"
  - 数据源、交互等关键配置需点击 "应用" 生效，避免误操作

- **配置项联动**：
  - 关联配置项自动折叠 / 显示，如关闭 "标题显示" 后，标题设置分组自动折叠
  - 选择 "图表组件" 后，自动展开 "组件特有配置 - 坐标轴设置"

- **快捷键支持**：
  - Ctrl+S（应用）
  - Ctrl+Z（重置当前 tab）
  - Esc（关闭面板）
  - Tab（切换配置项）

- **错误提示**：
  - 配置错误时（如 ID 重复、SQL 语法错误），对应配置项标红，底部显示红色提示文字，点击提示可定位至错误项

- **配置模板**：
  - 支持导入 / 导出组件配置 JSON，内置常用模板（如 "销售柱状图模板""日期筛选器模板"），一键应用

- **多语言支持**：
  - 配置项名称、提示文字、按钮文本支持中英文切换，与系统语言保持一致

- **配置项搜索**：
  - 组件属性 tab 支持配置项搜索（顶部搜索框），输入关键词快速定位目标配置（如搜索 "颜色"，高亮所有颜色相关配置项）

## 五、扩展能力设计

### 5.1 组件类型扩展

- 预留组件特有配置的 JSON 配置接口，新增组件类型时，仅需通过配置文件定义特有配置项的分组、字段类型、默认值、校验规则，面板自动加载，无需修改核心代码
- 支持自定义组件的配置项注入，通过插件方式添加专属配置分组（如新增 "AI 分析配置" 分组）

### 5.2 数据源类型扩展

- 支持新增数据源类型（如 Hive、ClickHouse、MongoDB），通过注册驱动插件扩展数据库选择列表
- API 接口支持自定义响应解析器，适配特殊格式的接口返回数据（如加密数据、特殊结构 JSON）

### 5.3 交互动作扩展

- 支持新增动作类型，通过脚本注册方式添加自定义动作（如 "发送邮件""推送企业微信消息"）
- 自定义脚本动作支持 JavaScript 编写，提供组件值、全局参数、数据源的访问 API，支持调试模式

## 六、兼容性与适配

### 6.1 浏览器兼容

支持 Chrome（90+）、Firefox（88+）、Edge（90+）、Safari（14+）

### 6.2 响应式适配

- 屏幕宽度 < 1440px 时，面板自动折叠为图标，点击展开后操作
- 屏幕宽度 < 1024px 时，支持面板浮层显示（可拖拽移动）

### 6.3 无障碍适配

- 所有配置项支持键盘导航（Tab 切换、Enter 确认）
- 颜色配置支持屏幕阅读器识别
- 表单元素添加 aria 标签

## 七、优化亮点总结

1. **简化 tab 结构**：将 "组件基础属性" 与 "组件特有属性" 合并为 "组件属性" tab，减少用户切换成本，按逻辑顺序排列配置项，更符合操作习惯

2. **按需动态加载**：组件特有配置、数据源子配置、交互动作参数均按实际类型动态加载，避免冗余配置项，提升面板简洁性

3. **增强交互体验**：新增配置项搜索、实时预览优化、错误定位功能，降低操作门槛

4. **统一配置框架**：所有组件共用 "基础属性 + 数据源 + 交互" 的配置框架，保持操作一致性，同时预留扩展接口，支持系统长期迭代
